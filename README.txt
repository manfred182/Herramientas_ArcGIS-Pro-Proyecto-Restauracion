Topografia Inteligente - Sistema Profesional

Instalación:

ArcGIS Pro:
- Abrir Catalog
- Add Toolbox -> seleccionar Topografia_PRO.pyt

ArcMap:
- Abrir ArcToolbox
- Add Toolbox -> crear Script Tool y apuntar a topografia_script.py

Funcionalidades:
- Compatible con cualquier sistema de referencia
- Conversión automática a WGS84
- Cálculo de coordenadas DMS
- Exportación opcional a Excel
